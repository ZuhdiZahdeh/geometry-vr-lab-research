# تصميم وتطوير مختبر الهندسة بالواقع الافتراضي

الموقع البحثي المستقل لمختبر الهندسة بالواقع الافتراضي، إعداد **زهدي زاهدة**. يحفظ نص البحث المرفق المؤرخ في **29 يوليو 2026** ويضيف توثيق التطوير اللاحق، بما يشمل دمج مرحلة التهيئة واستكشاف المجسمات والإرشاد الصوتي.

## محتوى الإصدار الإلكتروني 0.1.0

25 صفحة عربية، تشمل خمسة فصول، وعشرة ملاحق، والملخص، والمراجع، والوسائط والسجلات، والتنزيلات، وهوية الإصدارات والاستشهاد. لكل فصل صفحة واحدة وروابط مباشرة لأقسامه. تتضمن الحزمة سبعة فيديوهات توثيقية سابقة وصور المصدر ولقطات منتقاة للمقاطع المستوية.

هذه **دراسة تصميم وتطوير**، ولم تُنفذ ضمنها دراسة أثر على عينة من الطلبة. تفصل الصفحات بين نص يوليو التاريخي، ووثائق التنفيذ، وإفادة المطور عن التشغيل، والاختبارات التي لم تُستكمل أدلتها بعد. بيانات المراجع منقولة من الملف المرفق؛ لم تكتمل مراجعة صحتها الخارجية في هذا الإصدار.

## الصيانة والبناء

الموقع ثابت بلا مكتبات تشغيل خارجية. ملفات HTML المنشورة تُبنى من مصادر محتوى قابلة للصيانة:

```bash
python scripts/build_site.py
python scripts/validate_site.py
```

يتطلب البناء Python 3.9 أو أحدث. لا يحتاج إلى npm أو مفاتيح API. انشر فرع `main` من جذر المستودع عبر GitHub Pages. الملف `.nojekyll` يبقي المسارات كما هي.

| المجلد | وظيفته |
|---|---|
| `content/` | المحتوى المنقول والمادة التحريرية الجديدة بصيغة JSON ونسخ Markdown للقراءة |
| `chapters/` | صفحات الفصول الخمسة الناتجة عن البناء |
| `appendices/` | الملاحق أ–ي |
| `assets/` | التنسيق والبحث والصور والفيديوهات المنتقاة |
| `data/` | فهرس البحث وسجلات الوسائط وخريطة صفحات الموقع |
| `downloads/` | ملف البحث المرفق وخريطة المحتوى وسجل Excel |
| `docs/` | وثائق التنفيذ والصوت وتقارير التحقق |
| `scripts/` | استخراج المحتوى وبناء الصفحات وفحص الروابط |

ملفات `content/source.json` و`content/editorial.json` هي مرجع بناء HTML. نسخ Markdown المرافقة تُستخدم للقراءة والمراجعة؛ لا تُعدل HTML الناتج لتغيير المحتوى. عند استخراج نسخة مصدرية جديدة استخدم `python scripts/extract_content.py --help`، ثم راجع الفروق قبل استبدال المصدر التاريخي.
