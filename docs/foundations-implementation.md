# تنفيذ مرحلة اكتشاف المجسّمات

مشهد العمل: `Assets/VR_LearningHub_Foundations_Working.unity`.
إصدار المشروع: Unity `6000.4.1f1`، وحزمة XRI `3.4.0`.

## تشغيل النسخة

1. احفظ عملك في Unity وأغلق المحرّر قبل تبديل الفرع.
2. في GitHub Desktop: Fetch origin ثم اختر الفرع `cleanup/foundations-2026-09-21` لتجربة نسخة التنظيف.
3. افتح المشروع، وانتظر اكتمال الاستيراد وتجميع السكربتات.
4. من القائمة `Geometry VR > Foundations > Open Working Scene` افتح المشهد.
5. شغّل `Geometry VR > Foundations > Validate Open Scene`، ثم Play.
6. اختبر بالنظارة قبل اعتماد التغييرات أو دمجها في main.

تتولّد لوحتا التعليم والمقارنة ومحطة الفحص وأهداف تحديد الخصائص عند Play؛ لا تحتاج إلى ربط مراجع Inspector يدويًا. أُعدّ المشهد نفسه للمبنى التجريبي في EditorBuildSettings. إذا كان لديك Build Profile يستخدم قائمة مشاهد مستقلة، اختر هذا المشهد في ذلك الملف أيضًا.

## ما تغيّر

- أضيف `STAGE_01_FoundationsRoot` الذي يجمع Onboarding وSolids. أزيلت العناصر القديمة المستغنى عنها من مشهد العمل في تنظيف 2026-09-21؛ تفاصيل المحذوفات والرجوع في [سجل التنظيف](CLEANUP_2026-09-21.md).
- تستخدم المهام المكعب والأسطوانة والكرة الأصلية نفسها، مع التجاويف الأصلية. حُدِّدت Colliders الإمساك صراحة كي لا تستحوذ على أهداف الخصائص المضافة. رُبط Attach Transform بالمجسّم المرئي لمعالجة إزاحته عن جذر الإمساك.
- المهمة 1: اختيار المجسّم ذي الوجوه المربعة، ثم أي وجه وحافة ورأس، ثم الوضع الصحيح.
- المهمة 2: اختيار المجسّم ذي القاعدتين الدائريتين، وتحديد القاعدتين المختلفتين بأي ترتيب، ثم الوضع الصحيح.
- المهمة 3: اختيار المجسّم الذي لا يملك سطحًا مستويًا، ثم الوضع الصحيح.
- `PropertyValidated` و`CurrentlyDocked` و`TaskCompleted` حالات منفصلة؛ إخراج المجسّم المكتمل لا يمحو الإنجاز.
- يظهر نجاح 3/3 مرة واحدة لكل محاولة. زر الانتقال إلى التحويلات يدوي. يمكن الاستمرار في الاستكشاف.
- وضع Learning يظهر الألوان والمقارنة. وضع Test يخفي الإجابات والألوان، ويُظهر هدف التحويم بلون محايد. Help وإعادة إظهار Learning أو تشغيل الفيديو أثناء المهمة تُسجّل مساعدة.
- زر `Switch to grab` يخفي أهداف الخصائص لتسهيل إعادة الإمساك؛ `Inspect features` يعيدها. يمكن استعمال اليد الأخرى لاختيار خاصية في مجسّم ممسوك.
- `Return unfinished solids` يعيد المجسّمات غير المكتملة ويحفظ تقدّم الخصائص. `New attempt` يبدأ محاولة جديدة ويحتفظ بسجلّ القديمة.
- تحرير الإمساك يسبق إخفاء المرحلة، مع انتظار معالجة XRI المتأخرة وإعادة الأصل والموضع. مدير المرحلة يبقى خارج الجذر الذي يُخفى.
- أزيلت مكوّنات الصوت القديمة الخاصة بـ Onboarding وSolids من هذا المشهد. المنسّق يوقف الصوت والفيديو والمؤقتات عند تبديل المهمة أو المرحلة. تستخدم Foundations تسجيلاتها الحالية وتعليق النجاح، مع الاحتفاظ بإيقاف أصوات المراحل اللاحقة عند الانتقال.
- يوجّه زر Solids القديم إلى Foundations للمحافظة على روابط التنقّل القديمة. Next يتجاوز المرحلة القديمة ويتجه إلى التحويلات بعد استيفاء المهام.

## التتبّع

يمتد `DataTraceLogger` دون تغيير واجهاته القديمة. تُحفظ أحداث JSONL تحت:
`Application.persistentDataPath/FoundationsTraces/`.

كل حدث يحتوي وقت UTC، ومعرّف محاولة عشوائيًا، والنمط، وعدد المساعدات والمهام المكتملة. تُفصل فئة `geometry_error` عن `motor_error`، وتُسجّل الاختيارات، والخصائص، والوضع والإخراج، وإعادة الضبط، والنجاح والتنقّل. لا يتضمن السجل أسماء طلاب. إذا تعذّر حفظ الملف يبقى السجل في الذاكرة مع تحذير في Console.

## اختبار القبول داخل Unity والنظارة

| التجربة | النتيجة المطلوبة |
|---|---|
| فتح المشهد وPlay | لا أخطاء تجميع أو Missing Script، ظهور اللوحتين والمنصّة ومحطة الفحص |
| التجوال والإمساك قبل Begin | لا تُحتسب المهام أثناء الاستكشاف الحر |
| وضع المجسّمات الثلاثة قبل حلّ الخصائص | لا يظهر النجاح |
| اختيار مجسّم خاطئ | تغذية راجعة وتسجيل geometry_error، دون تقدّم |
| المكعب: وجه ثم حافة ثم رأس | يقبل أي عنصر صحيح؛ اختيار نوع خاطئ لا يحتسب |
| الأسطوانة بعد تدويرها | تقبل القاعدتين بأي ترتيب؛ تكرار القاعدة نفسها لا يحتسب ثانية |
| وضع المجسّم في التجويف الخاطئ | لا يلتقطه التجويف؛ تُسجّل motor_error مرة خلال فترة التهدئة |
| إخراج مجسّم بعد اكتماله وإعادة وضعه | يبقى الإنجاز ولا يتكرر النجاح |
| التحويل بين Test وLearning وHelp | تظهر وتختفي الإجابات؛ المساعدة مسجّلة |
| إعادة المجسّمات أثناء الإمساك | يعود غير المكتمل إلى موضعه دون رمي أو فقدان تقدّم الخصائص |
| New attempt | يعود الجميع، يصبح التقدّم 0/3، ويبقى سجلّ المحاولة السابقة |
| طلب الانتقال قبل الإكمال | يُمنع الانتقال وتظهر رسالة السبب |
| الانتقال بعد 3/3 مع إمساك مجسّم | يتحرّر قبل اختفاء الجذر؛ يبقى Rig فعالًا |
| العودة عبر زر Onboarding أو Solids | تعود Foundations مع الإنجاز المحفوظ |
| تشغيل فيديو ثم تغيير المهمة أو المرحلة أثناء التحضير | يتوقف ولا يعاود التشغيل بسبب callback متأخر |
| اختبار Quest لمدة عشر دقائق | وضوح النص، سهولة إصابة الأهداف، ملاءمة ارتفاع الطاولة ومحاذاة التجاويف، وعدم تدهور الأداء |

الفحص الآلي في المحرّر متاح أيضًا عبر `Geometry VR > Foundations > Run Progress Checks`، دون إضافة حزمة اختبارات. يفحص منطق التقدّم والحالات الحدّية؛ لا يحاكي فيزياء XRI أو جهاز Quest.

## التحقّق المنفّذ خارج Unity

- فحص صياغة ملفات C# بمحلّل لغوي.
- فحص بنية YAML والمراجع والتسلسل الهرمي وملفات meta وإزالة عناصر المسار القديم ومشهد البناء عبر `python Tools/validate_foundations.py` (يتطلب PyYAML). يضيف `python Tools/validate_project_cleanup.py` فحص المحذوفات ومراجع GUID، ويفحص `python Tools/validate_foundations_voiceover.py` سلامة التسجيلات وروابطها.
- لم يُشغّل Unity أو Android build أو Quest في بيئة التعديل. فحوص C# الدلالية، وقائمة الاختبارات في المحرّر، واختبارات التفاعل أعلاه ما تزال مطلوبة؛ نجاح فحص الصياغة لا يعني نجاح التجميع.

## نطاق الرجوع

التعديلات في فرع مستقل. أُرشفت الملفات والمشاهد المحذوفة في `archive/pre-cleanup-2026-09-21` قبل التنظيف. المشاهد الباقية التي لا تسند `m_Foundations` في LearningStageController تحتفظ بمسار تنقّلها السابق. للعودة إلى النسخة السابقة مباشرة، احفظ عملك وأغلق Unity، ثم بدّل إلى فرع الأرشيف في GitHub Desktop. لا يحتوي الأرشيف على أي عمل محلي غير مرفوع إلى GitHub.
